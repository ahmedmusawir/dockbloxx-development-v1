## Lessons Learned

- **Write the RESPONSES mirror before displaying, even inside Plan Mode.** I deferred it to plan-exit and Tony caught it. If the harness blocks the write, say so instead of silently deferring.
- **Repo `src/` is CRLF.** Python text-mode writes converted two files to LF and produced a 2,500-line phantom diff. Edit in binary mode and check `git diff --stat` after every `src/` write. Tests are LF.
- **Pressable edge cache (`x-ac`) serves the ACF options endpoint stale for minutes.** Cache-bust (`?_nocache=<ts>`) before concluding a field is absent. Cost us one false GAP-1.
- **Browser checks must wait for the price effect** before clicking Add to Cart, or they capture `price 0`. Round products only offer size `Other`, and the existing `alert()` guard aborts the add; capture dialogs in Playwright.
- **Playwright scripts in the scratchpad need `NODE_PATH=<repo>/node_modules`**, and `networkidle` never settles on a dev page with HMR; use `domcontentloaded` plus an explicit wait.
- **A Director message can carry a literal placeholder** (`#<id>`). A read-only listing of recent orders resolved it in one call; mark inferred values as inferred until confirmed.
- **Anchored regex beats exact-string replacement** for long markdown lines with dashes and quotes.
